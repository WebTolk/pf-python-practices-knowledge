# Maintaining this knowledge package

Read README.md, NOTICE.md and MAINTAINING.md first. Preserve the package and resource ids, original source attribution and per-document licenses. Work on a branch and use a pull request into main for subsequent changes. Keep the exact archive recipe and updates manifest consistent, and require the Windows and Linux package checks before publishing a new version. Never overwrite released assets or include private PF state, device paths, credentials or caches. Load only the reference documents relevant to the task.
