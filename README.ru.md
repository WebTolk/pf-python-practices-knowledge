# Python Patterns and Recipes

[English](README.md) | Русский

Общий обновляемый пакет знаний ProcessForge: `docs.python-practices`, ресурс `root`, версия `1.0.1`. Включает 14 Markdown-файлов существующего снимка с исходными ссылками и датами получения. Тексты документов сохранены без изменений.

[Оглавление](resources/README.md) · [Релизы](https://github.com/WebTolk/pf-python-practices-knowledge/releases) · [Сервер обновлений](https://github.com/WebTolk/pf-python-practices-knowledge/releases/latest/download/python-practices.json) · [Происхождение и лицензии](NOTICE.md).

Скачайте ZIP и JSON-манифест одной версии релиза, проверьте SHA-256 и распакуйте содержимое в `docs.python-practices/` выбранного корня пакетов PF. Проверьте пакет командой `knowledge-package-doctor`. Для проекта под управлением PF включите его в `requirements.knowledge_packages` и обновите контекст и индекс поиска. При разработке самого ProcessForge следуйте его CONTRIBUTING и инструкции подготовки устройства; корневая `.pf` для этого не требуется.

PF получает следующие версии через `update_sites`; применение выполняется явной командой после подготовки и проверки архива. Перед заменой существующей установки сохраните резервную копию. Команды и порядок сопровождения приведены в [английской инструкции](README.md) и [MAINTAINING.md](MAINTAINING.md).
