# Provenance and licensing

This package preserves 14 Markdown files from the existing `docs.python-practices` 1.0.0 snapshot. WebTolk adds portable PF metadata, indexing, attribution and release packaging. The Markdown document bytes are unchanged. The earlier snapshot converted official web documentation to Markdown; original URLs and capture dates remain in each document and in `sources.json`. This release does not claim to refresh or reproduce an entire upstream website.

Only the categories represented by documents in this package apply. `sources.json` maps each document to its source and terms. Full applicable license texts and their original sources are under `licenses/` and `sources.json`.
